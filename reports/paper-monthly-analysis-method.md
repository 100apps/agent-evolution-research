# 十会议论文目录按年、按月分析：口径与验收

## 假设与证据等级

对主目录 89,530 条会议来源出现记录，按会议届次年聚合可以得到该目录覆盖范围内的年度数量。来源快照覆盖不等于完整全球论文量，2026 年尚不完整。月度数据只有部分记录有可核验的书目月份；其余记录按用户指定的固定标题哈希映射为 1–12 月，属于展示用的合成月份，不能证明真实发表季节性或月度增长。

证据等级：来源核验与本地确定性数据变换。月度填补是合成展示机制，不升级为真实月度观察。

## 输入与费用边界

- 主表：`research_trends/catalog/data/master_papers.csv.gz`，以 `data/master_receipt.json` 的 SHA-256 为准。
- 月份补充：`research_trends/catalog/metadata_snapshot/metadata_patch.jsonl.gz`；仅接受 `date_precision` 为 `month` 或 `day` 且 `date_type` 为 `proceedings_bibliographic_date` 的 `publication_date`，按 `occurrence_id` 精确关联。
- 离线、标准库构建；不请求外部服务、不调用付费 API、不运行第三方项目代码。
- 可分享成品是 `reports/paper-monthly-analysis.html`。其中内嵌从原 69 列主表投影出的全部 89,530 行、10 列分析所需 CSV，gzip 后 6,801,133 字节、解压后 21,077,844 字节；页面内 JavaScript 自动解压并在内存中计算。构建模板为 `tools/monthly_catalog_template.html.in`，不是供打开或分享的报告。

## 验收条件

1. 内嵌的压缩 CSV 解压后仍有 89,530 条记录，能从本地 `file://` 在浏览器内加载和聚合。
2. 年度计数仅使用原会议届次年份，年度总数与主表一致，所有年份合计 89,530；按会议筛选亦能复核。
3. 已核验月份与虚拟月份分开显示，缺月份只用固定标题哈希映射；相同输入重复打开结果不变。
4. 可按年、按月查看会议和一级、二级、三级分类的数量、明确分母的占比及趋势。多标签重复计入分类时说明占比之和可超过 100%。
5. 页面单文件离线使用、全宽响应式布局，宽屏和移动端无横向溢出；不发外部网络请求。
6. 保留构建命令、源与输出 SHA、实际数量、浏览器检查结果及任何失败。

## 交叉表口径

- 行树为 `ALL → 来源（会议）→ 一级 → 二级 → 三级`。分类路径从已保存的 L3 ID 回溯 taxonomy 的 L2/L1；同一条记录在一个节点内只计一次，跨不同候选分类可重复出现。
- 列为 `总计 → 会议届次年合计 → 该年 12 个月`。月份使用已核验书目月份或页面内标题哈希虚拟月份；年合计与月明细是父子关系，不能一起求和。
- 单元格行占比 = 格内记录数 ÷ 该行所有年份记录数；列占比 = 格内记录数 ÷ ALL 在对应总计/年/月的记录数。底色条长可切换行占比或列占比，100% 为整格宽。
- 单元格弹窗使用内存中对应节点的记录索引再按年/月筛选，每页 25 条；显示标题、来源、会议届次年、真实/虚拟月份、paper ID、occurrence ID 和原始公开链接。
- 行树和聚合均在 HTML 加载后由 JavaScript 从解压 CSV 计算；初始只渲染 ALL 与来源，行和年份按需展开。
- 全屏按钮优先调用浏览器 Fullscreen API；不可用时在当前窗口铺满视口，Esc 或按钮退出。可分别展开全部行、全部月份，也可一次展开行列；大量单元格按帧分批绘制，新的操作会取消上一轮未完成的绘制。

## 限制

年度“准确”仅指已采集会议来源出现记录按会议届次年的机械聚合，不代表已去重论文总数、全球论文总数或完整的 2026 年。混合真实月与虚拟月的曲线不可用于解释真实季节变化；虚拟月占比必须持续可见。
