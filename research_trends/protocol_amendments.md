# 采集后协议变更记录

## 2026-10-09 03:30 UTC：OpenAlex 日期首日堆积

2020-01、2020-09、2023-01、2023-09、2026-09 的已缓存 API 单日计数显示每月首日占比依次为 83.65%、20.70%、73.09%、16.00%、14.70%。这来自实际查询，不证明具体缺失日字段如何填补。原 `group_by=publication_date` 探针 5 次均 HTTP 400，已记录，未当零。

在全量月度结果分析前，加入预定的诊断性敏感性：对 81 个月每月 1 日以与主系列完全相同的三项过滤口径重算，并报告首日占比，以及剔除首日后的剩余作品 AI 份额。主系列不被更换或删掉；敏感性不能修复全部日期偏差。第一天也可能有真实发表，因此剩余 2–月末并非“真实产出”的无偏估计。年度计数仍受发表/收录滞后与字段变动影响。

此项是在看过 5 个 pilot 月份后添加的探索性诊断，不属于采集前确认性假设。

## 2026-10-09 03:50 UTC：共享顶会标题规则 v1→v2

首次应用共享标题词表后，发现 explicit_language_foundation 含不带限定的 language model，会把较早的一般语言模型论文误写成“明确基模”。v2 删除这一短语，仍保留 large language model、LLM、foundation model 等明确词；单独的历史预训练词条保留为敏感性。修改发生在查看 v1 的 2020 与 2025 标签占比之后，因此顶会标题结论全部是探索性；v1 规则的更改可由 Git diff 与本条记录追踪。最终所有 venue-year 统一重跑同一个 v2 文件，记录 SHA，禁止混用 v1/v2。
