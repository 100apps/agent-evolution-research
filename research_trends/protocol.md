# 研究活动与人员再分配：分析协议

版本 2026-10-09 UTC。此为本地分析计划，不声称公开预注册。2020-01、2023-01、2020-09、2023-09、2026-09 的 OpenAlex 小样本已先行查看；这些点不能当成预注册后的确认性结果。后续更改需记录原因和时间。

## 问题与可观察总体

- H1：AI 相关论文的绝对量及在可覆盖科研论文中的份额是否增长？具体传统任务域的绝对量、份额分别如何？
- H2：可识别作者的论文组合是否转向 AI、是否减少原方向，而非只是多做一个方向？
- H3：AI 内部的基模、预训练、后训练、Agent、应用、基础设施的产出与占比如何变化？
- H4：既有 39 篇 Agent 进化研究是否有未解决而可交付的研究机会？热度本身不足以证明价值。

总体仅为各来源所覆盖的产出、职位或资金，不是世界全部科研人员或劳动时间。39 篇既有论文只作背景，不是行业抽样框。

## 固定来源与主口径

OpenAlex 当前 API 默认 core 语料，按同一抓取版本回溯 2020-01 至 2026-09。研究作品类型固定为 `article|preprint|conference-paper|review` 且 `is_retracted:false`。评论文章 `review` 在图表单列敏感性；类型新规则与过往重新归类可造成变化。以 work ID 为单位，OpenAlex 将同一作品多个位置合并，但剩余漏合并和误合并需抽检。`publication_date` 是主位置的发表日，不保证是首次公开日期。

全部领域分母为符合上面规则的 OpenAlex works；计算机分母为 `primary_topic.field.id:17`；窄 AI 为 `primary_topic.subfield.id:1702`；AI+视觉敏感性为 `1702|1707`。这是主主题代理，不覆盖所有利用 AI 的应用论文，且不能将全部 CS 当 AI。主领域分组包括未知，核验分组和等于 `meta.count`。同月同时报告 AI/全部与 AI/CS，只有验证 AI 集合包含于 CS 才解释后一比率。

2026-10 OpenAlex 主题分类器更换：只用同一当前版本的历史回溯，不拼旧快照；记录抓取 UTC 时间、URL、SHA、分类版本和 API 口径。所有指标以缺失区别于零。月度最近 3/6/12 个月分别剔除做结论敏感性；2026-09 为最后完整日历月但索引未必成熟，不把 2026-10 当完整月，不按模型补出“事实”。

arXiv 以首次提交日期为另一个独立月度来源，按 base ID 去版本；core5 AI 并集固定为 `cs.AI|cs.LG|cs.CL|cs.CV|stat.ML`。扩展 `cs.NE|cs.MA|cs.RO` 另列敏感性。core5 含 `stat.ML`，计算 core5/CS 时分子须与 `cat:cs.*` 相交。各类重叠，以布尔并集去重，不相加；不将 arXiv 与 OpenAlex 总数相加。arXiv 作者姓名不是唯一人员 ID。

## 两轴分类与交叉

任务域：信息检索、推荐、广告营销、软件工程、其他工程、算法理论、其他；方法：非 AI、非基模 AI、基模、预训练、后训练、Agent、应用、基础设施、评测安全、未知。两轴及轴内标签可以重叠，报告领域总量、领域×AI、领域×基模、领域×Agent。所谓传统方向必须明确定义，例如“推荐且无基模方法”；不能将推荐或算法整体从 AI 排除。若需合计为 100% 的构成图，另定义唯一主贡献标签，并列未知。

Agent 狭义需有模型参与的目标导向行动—环境/工具观察—反馈迭代闭环。广义历史 AI agent 另列。Agent 进化还要编码修改目标、发生时间、反馈、持久性、参数是否更新。严格/宽松关键词查询首先仅为候选论文；用按年份分层的正负样本做人工审阅，并公开误判与不确定。半月结果只有真实日期、稳定索引、足够样本和分类精度同时支持时才解释，否则只给月度。

## 作者、职位与资本

作者只做固定种子、明确 2020 起源分层的条件性面板。取 2015–2026 观察历史，主要比较 2020–21 与 2024–25 的人内 AI 作品份额；列双向流量、混合采用、无后续可见作品、历史不完整。旧方向绝对作品量未减者为扩展而非转行。不得将月内发文 ID 数当在职研究者人数，不把首次观察当职业入行。作者 ID 误合并/误拆分、2023 消歧变动、ORCID 选择偏差、前 100 作者截断均需审查。预算不足时缩小事先说明的样本，不静默替换作者。

招聘是岗位需求，融资是资本流量，开源是开发者活动，UNESCO 年度 FTE 是总体研发劳动密度：逐来源保留地理范围、年份、单位和分母，不插值伪造月度，不合成“全球 AI 研究者人数”。

## 比较、反证和结论

每类给原始月值、同月同比、滚动 12 月绝对量与份额。份额变化用百分点，接近零基数同时报基数。明确绝对下降与份额稀释。近期滞后、年/月首日日期堆积、源覆盖变化、分类器漂移、疫情、会议季节性均为替代解释；不以描述性时间折点推断因果。结论分别标 `supported`、`partially supported`、`unsupported`、`unknown`，并指明覆盖范围。人员总迁移若只有论文量，必须为 `unknown`。项目价值须核对邻近竞争、对照、预算与可交付研究缺口，不能从 Agent 论文增加自动推出。

最低交付：字段词典、查询和分类清单、原始响应与 SHA 审计、月度 CSV/JSON、质量标记、来源分离图、交叉矩阵、作者面板流量及缺失、反证和四项结论。所有负面运行、HTTP 失败与协议修改保留。
