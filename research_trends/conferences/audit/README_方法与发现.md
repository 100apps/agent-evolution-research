# agent / tool / memory 标题口径：60 篇摘要内容审计

## 结论先行

这次小样本 AI 辅助阅读支持一个较窄的结论：同一组 agent / tool / memory 标题词，在早期更多指传统强化学习、多主体方法或普通对话；近年样本中出现了清晰的 LLM 行动—观测闭环，但仍混入大量普通 RAG、记忆模块、对话系统和辅助训练方法。因此，标题命中数不能直接当作“LLM agent 论文数”。

60 篇中，15 篇归为“核心 LLM agent 闭环”，23 篇为“非 LLM RL / 多主体方法”，15 篇为“其他工具 / 记忆 / 对话等用途”，7 篇仅靠摘要不足以确定。标签是单一 AI 阅读者的可复核判断，既不是人工金标准，也不是全文审核。

## 抽样总体、分母与缺失

仅使用现有本地官方来源元数据，不新增网络查询，不使用 arXiv。ML 为 ICLR、ICML、NeurIPS 主会记录；NLP 为 ACL 主会长短文并集。比较 2020–2022 与 2024–2026；不抽取 2023。CVPR 未纳入，因为已收集数据没有摘要。

首先固定沿用 ml/title_topic_rules.json 中 agents_tools_memory 的宽标题正则，再限于有非空已收集摘要的论文。正则覆盖 agent、agentic、指定 tool-use / tool-calling 等形式、function calling、retrieval-augmented / RAG、指定长期/情景/增强记忆和 world model 等；它不是所有可能同义词的完整词典。规则没有根据本次标签调优。

NeurIPS 2026 的会前节目不完整，整体排除：5,522 条记录，其中标题词命中 432 篇，有摘要 286 篇。ICML、ICLR、ACL 2026 保留；以已收集正式来源和既定主会筛选为准，不将这一审计作为重新核验录用状态或未来最终论文集完整性的证据。

标题阳性总体为 2,557 篇；可抽样摘要总体为 2,543 篇。ML 早期摘要覆盖率为 218/232 = 94.0%，其余三个标题阳性分层均为 100%。14 篇阳性缺失均来自 ICLR 2020。所有论文层面，ICLR 2020 缺 687 篇摘要；ACL 近年另有 2 篇缺摘要，但都不在本次标题阳性总体内。

这不是按会议所有论文随机抽取的样本，也不包含标题漏检的 agent 论文。无法估计召回率，无法把审计比例直接解释为全会 agent 论文份额。

## 可复现选择方法

固定种子 20261009。每层独立使用 Python random.Random("20261009:" + stratum)；先按会议、年份、稳定论文 ID 排序，再无放回抽样。ACL 早期仅 11 篇，因此全部阅读；其他层固定抽取 16、17、16 篇，共 60 篇。该数量分配在读取摘要之前固定。最终抽样是在按要求排除 NeurIPS 2026 后、阅读摘要前冻结的。

sampling_manifest.json 保存正则原文、四层分母、逐会议逐年摘要覆盖、种子、Python 版本、输入文件 SHA-256 与 NeurIPS 2026 排除数量。各论文记录保留纳入概率、逆概率权重和摘要 SHA-256。

## 判定口径

- central_llm_agent_loop：语言模型或语言基础 VLM 是任务决策/控制器；研究核心涉及环境/工具/其他主体中的多步行动与观测、结果或反馈。直接训练、评测、安全或验证这类流程也包括在内。反馈式检索可以包括，但只出现 RAG 字样不够。
- non_llm_rl_multiagent：传统/非语言 RL、控制、多主体规划预测或去中心化优化。这里的“非 LLM”描述方法主体，不表示论文必须年代较早。LLM 仅辅助生成 RL 奖励，而主要执行者仍是 MARL 策略时，也放在此类并标记辅助角色。
- incidental_tool_memory_other：普通 RAG、静态函数格式输出、视觉或持续学习记忆、常规聊天/角色扮演、非语言物理世界模型等。词语可能是论文核心，但不满足这里的行动型 LLM agent 定义；“other”不是说该研究不重要。
- unclear_from_abstract：摘要显示相关方向，但不足以确认语言大模型控制器身份或闭环机制。不能由标题的 Agent / LLM 或研究年份自动补齐证据。

对每篇实际阅读标题与完整已收集摘要。结果含 25 词以内的原文证据、中文理由、置信度、LLM 角色、闭环判定和论文 URL。证据已逐条用程序核对为摘要的精确子串；URL 来自原始官方来源元数据，没有在本审计中重新联网访问。某些“有反馈”的判断依据摘要中交互轨迹、工具执行或环境奖励作语义推断，未要求原文出现固定的 action–observation 字样。

## 分层结果

| 分层 | 核心闭环 | 非 LLM RL / 多主体 | 其他 | 不确定 | 核心比例 |
|---|---:|---:|---:|---:|---:|
| ML 2020–2022，n=16 | 0 | 14 | 0 | 2 | 0/16 |
| ML 2024–2026，n=17 | 7 | 5 | 3 | 2 | 7/17 = 41.2% |
| ACL 2020–2022，n=11 | 0 | 4 | 6 | 1 | 0/11 |
| ACL 2024–2026，n=16 | 8 | 0 | 6 | 2 | 8/16 = 50.0% |

不能将早期样本的 0 解读为“当时不存在”。例如 Zero-Shot Planners 已明确用 LLM 生成计划，WebShop 已明确研究网页交互；它们分别因为摘要没有充分确认反馈闭环、没有充分确认 LLM 控制器而被保守放入不确定。早期 ACL 的语言模型多主体自博弈也保留为边界项。

若将每层所有不确定项都改算为核心，四层比例分别为 12.5%、52.9%、9.1%、62.5%。这是本套分类内的敏感性上下界，不是置信区间，也没有覆盖其他已判标签可能出错的情形。

逆概率加权后，2,543 篇可抽样标题阳性总体中，核心闭环的点估计为 39.5%，非 LLM RL / 多主体为 27.6%，其他为 20.9%，不确定为 12.0%。加权合并值受到近年总体更大的影响，不应拿来代替分时期比较；60 篇直接合并的 15/60 = 25% 也不是总体估计。

样本很小。按各层无放回抽样，反演 Hypergeometric(N, K, n) 得到整数总体核心篇数 K 的等尾精确 95% 区间，再除以 N：ML 早期为 0–19.7%，ML 近年为 18.5%–66.9%，ACL 近年为 25.0%–75.0%。这些是各层边际区间，未作同时覆盖校正，且已精确纳入有限总体大小。ACL 早期是 11 篇全查，固定标签下的区间为 [0,0]，但仍有一篇分类不确定，不能解读为总体概念上绝无早期 LLM agent。

加权总体的不确定性使用分层设计方差 Var(p_hat)=Σ(N_h/N)²(1−n_h/N_h)s_h²/n_h；s_h²=n_h p_h(1−p_h)/(n_h−1)，明确包含有限总体修正。严格核心估计的标准误为 8.80 个百分点；把全部不确定都算作核心后的上界估计为 51.5%，设计标准误为 8.91 个百分点。不报告合并二项置信区间。零命中层的插件方差为零，不代表真实抽样不确定性为零，故另给上面的精确分层区间。所有这些抽样区间和标准误均条件于本次 AI 标签，不包含编码错误、词典漏检、缺失摘要或来源覆盖误差。

## 摘要中明确可见的核心闭环例子

这些例子均来自预先抽出的 60 篇，不是额外定向挑选到样本中。

- diff History for Neural Language Agents，ICML 2024：对连续环境文本观测做差分，作为 LM 策略的交互历史。[论文](https://proceedings.mlr.press/v235/piterbarg24a.html)
- OSDA Agent，ICLR 2025：LLM 生成候选、调用化学评估器，再据评估反馈反思和改进。[论文](https://openreview.net/forum?id=9YNyiCJE3k)
- SceneGenAgent，ACL 2025：代码生成、布局验证、迭代改进。[论文](https://aclanthology.org/2025.acl-long.873/)
- PDAgent，ICML 2026：摘要明确列出 THINK、PLAN、ACT、OBSERVE、REFLECT 五阶段循环。[论文](https://proceedings.mlr.press/v306/ouyang26a.html)

## 文件与重现

- agent_abstract_audit.csv / .json：60 篇逐篇标签、短证据、理由、权重与论文链接；不重复完整摘要。
- audit_summary.json、audit_stratum_summary.csv：分层计数和条件总体加权汇总。
- sampling_manifest.json、stratum_frame.csv：总体、覆盖、随机种子、输入哈希与概率。
- sample_agent_abstracts.py：从既有本地数据重新生成相同样本。输出 audit_sample_unlabeled.json / .csv 为中间文件，含原始摘要供本地复核。
- label_agent_abstracts.py：应用已冻结的逐篇 AI 阅读标签，检查证据原文，并重建结果。该脚本不会自动重新判断文本，也不是训练过的分类器。
- validation.json：样本、证据、概率、去重和重现检查。
- audit_compact_transfer.json：小于 80 KB 的整合包，含全部 60 篇短证据和标签、方法、输入哈希及汇总。

执行顺序：python sample_agent_abstracts.py；python label_agent_abstracts.py。需要原始 ML 和 ACL 元数据文件与原标题规则文件保持不变。统计重现依赖 NumPy 和 SciPy；本环境为 Python 3.12、SciPy 1.17.0。不会发起网络请求。
