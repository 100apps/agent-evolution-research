# Harness 搜索验证集复用偏差：合成机制实验

复现等级：`机制示例`。这是统计模拟，不是 Meta-Harness、SoL-Pi 或 EvoC2F 的论文基准复现。

实验比较两种协议：

- `sealed_once`：所有候选仅按开发集选择；候选冻结后，独立验证集只评一次且不反馈回搜索。
- `reused_holdout`：每轮先按开发集选出一个候选，再反复查看同一验证集，并选择验证分最高的一轮。

两种协议使用相同的候选真实质量、相同开发集/验证集/最终测试集规模和固定随机种子。最终测试集从未参与选择，用来估计报告分数的择优偏差。

为让 3000 次 Monte Carlo 在纯标准库 CPU 上快速完成，开发集、验证集和最终测试集的二项准确率使用均值 `n·p`、方差 `n·p·(1-p)` 的正态近似，再裁剪并量化到 `1/n`；这不会被表述成真实基准数据。

运行：

```powershell
python run.py
```

输出：`results.json`、`round_curve.csv`、`run.log`。
